# 🌱 EcoCasa

**Economize recursos. Transforme seus hábitos.**

O EcoCasa é uma aplicação Web desenvolvida com o objetivo de incentivar o consumo consciente de água e energia elétrica dentro das residências. A plataforma permite que os usuários acompanhem seus consumos, estabeleçam metas de economia e adotem hábitos mais sustentáveis no cotidiano.

O projeto surgiu a partir da preocupação com o desperdício de recursos naturais e da necessidade de tornar o acompanhamento do consumo doméstico mais simples, acessível e visual.

---

## 🎯 Objetivo

Promover a conscientização ambiental por meio de uma aplicação que permita o acompanhamento do consumo de água e energia elétrica, incentivando a redução do desperdício e a adoção de práticas sustentáveis no ambiente doméstico.

---

## 🚀 Funcionalidades

- **Dashboard:** Visualização geral do consumo de água e energia, metas e indicadores.
- **Registro de consumo:** Cadastro manual do consumo mensal de água e energia elétrica.
- **Histórico:** Acompanhamento dos registros anteriores e comparação entre períodos.
- **Gráficos:** Visualização da evolução do consumo ao longo dos meses.
- **Metas de economia:** Definição de metas mensais para redução do consumo.
- **Dicas sustentáveis:** Recomendações práticas para economizar água e energia.
- **Desafios sustentáveis:** Atividades que incentivam a adoção de hábitos conscientes.

---

## 📊 Indicadores apresentados

### 💧 Consumo de água
- Consumo mensal em metros cúbicos (m³).
- Comparação com períodos anteriores.
- Acompanhamento de metas.

### ⚡ Consumo de energia
- Consumo mensal em quilowatt-hora (kWh).
- Comparação com períodos anteriores.
- Acompanhamento de metas.

## ⚙️ Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/EcoCasa.git
```

### 2. Acesse a pasta do projeto

```bash
cd EcoCasa
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute a aplicação

```bash
ng serve
```

### 5. Acesse no navegador

```text
http://localhost:4200
```
